TOP:Launcher

現在の参照先は module/ 配下です。流れは「JSON作成 → スライド生成プロンプト → Final Cut調整 → render」です。

会話を生成する module1:JSON作成を開く

Step 1

Project Launcher / JSON作成

会話ログから summary、hook、slide、scene、sub_scene、06-render-draft を作ります。

module/1_makejson.html
Step 2

Slide Prompt Builder 2

raw_conversation や slide_spec から、中央スライド領域向けの画像生成プロンプトを作ります。

module/2_slideprompt_builder.html
Step 3

Final Cut Panel

06-render-draft を読み込み、音声演出・字幕タイミング・背景/BGMなどを調整して render-final-v01.json に反映します。

module/3_Final-Cut-panel.html
Step 4 Render

Final Cutで作ったJSONをrenderするコマンド

Final Cut Panel の保存先 projects/{id}/outputs/video/render-final-v01.json を SCENE_RENDER_SPEC_PATH に指定して、Remotion側へ同期してから render します。

projects/0000/outputs/video/render-final-v01.json
remotion.config.ts を開く

Tool 1

Timing Calc

scene と subscene の入れ子カードで、文字数比率からstart / durationを自動計算します。

module/tool1-timing-calc.html
Tool 2

Hook Viewer Lens

完成済みの会話劇を貼り付けて、視聴者目線で刺さる点を分析するAI用プロンプト(GEMINI推奨)を生成します。

module/tool2-hook-viewer-lens.html
Tool 3

VOICEVOX Last Tone Checker

render-final-v01.json と生成済みwavを最後に耳チェックし、気になるsceneだけVOICEVOXで簡易再生成します。

module/tool3-voicevox-last-tone-checker.html
Tool 4

HOOK画像プロンプト生成

TOP / MAIN / SUB と会話内容から、YouTube Shorts冒頭0〜2秒向けのHOOK画像プロンプトを生成します。

module/tool4-hook-pic-builder.html
Tool 5

WAV Duration Checker

WAVファイルまたはフォルダを読み込み、各音声の再生時間を一覧確認してJSON / CSVで出力します。

module/tool5-wav-duration-checker.html
