render-final-v01.json の有効sceneをVOICEVOXの .vvproj に変換します。

render-final-v01.json を読み込んでください。

変換設定

ブラウザで直接 http://127.0.0.1:50021 を叩くとCORSで失敗することがあります。VOICEVOX Engineを起動し、別ターミナルで npm run voicevox:proxy を使う構成を推奨します。

話者別プリセット上書き

ずんだもん系 speed 1.44

pitch 0 / intonation 1

めたん系 speed 1.35

pitch -0.03 / intonation 0.8

読み込んだ、または生成済みの .vvproj に対して query.speedScale、query.pitchScale、query.intonationScale を上書きします。

wavリネーム補助

VOICEVOXの書き出しが 001_... の詰め連番になったとき、render-final-v01.json の有効scene番号に合わせて seg_001.wav 形式へそろえます。JSON読込後は project_id を使ってコマンドを自動更新します。

確認だけ
npm run voicevox:rename -- --project-id 0000 --dry-run
本番適用
npm run voicevox:rename -- --project-id 0000

まず --dry-run で対応表を見て、問題なければ本番コマンドを実行します。既存の seg_XXX.wav がある場合や、wav数と有効scene数が合わない場合は停止します。
