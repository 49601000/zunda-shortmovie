VOICEVOX Character Style Config v1

VOICEVOX Engine の /speakers からスタイル一覧を取得し、キャラクターごとの style id を設定します。ブラウザ制約回避のため、まず npm run voicevox:proxy を起動してから利用してください。sceneごとに「キャラクター → スタイル → speed」を選んだうえで一括WAV生成用JSONを作成し、initial を実行します。
