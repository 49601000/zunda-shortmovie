Movie Control Panel v1

scene_render_spec を1画面で調整し、HOOK/sceneの開始時間・持続時間、セリフ、VOICEVOXのキャラ/スタイル/speedを統合編集します。保存したJSONをそのままRemotionに読み込ませる前提です。

①Input scene_render_spec JSON

推奨パス: ./output/<runid>/spec/svrs_scene_render_spec.json（loadボタンは localStorageキー svrs_scene_render_spec を読み込み）

②Picture JSON 連携（HOOK / SCENE パーツ割当）

推奨パス: ./schema/picture.json（schema読込ボタンはこのファイルを参照）

picture.json 未読込

③Batch JSON (for WAV generation)

保存先パス: ./output/<runid>/audio/voicevox-batch-spec-<runid>.json（VOICEVOX batch実行時の参照先）

④Output scene_render_spec JSON（timeline + voice反映）

保存先パス: ./output/<runid>/spec/svrs_scene_render_spec.json（saveボタンは localStorageキー svrs_scene_render_spec にも保存）

⑤Terminal Command（動画生成）

ブラウザからnpm実行はできないため、コマンドコピーしてターミナルで実行します。Run IDは launcher の設定値を参照します。
