ショート動画制作ランチャー（Current Spec）

現在の推奨フローは「STEP1 Scene作成 → STEP2 WAV生成 → STEP3 画像+WAV統合の最終調整 → STEP4 render」です。旧 Timing Adjuster 導線は含めていません。

保存先 output/000/

この Run ID で output/000/ に保存します。

Step 1 Scene

Scene Renderer v1

通常シーン + Hookシーンを含む svrs_scene_render_spec を作成・編集。Hookは scene_type: "hook" として統合管理。

scene-renderer-v1.html を開く
Step 2 WAV

WAV生成（複数キャラ）

scene_render_spec をもとに複数キャラの VOICEVOX 生成を行います。Run ID、保存先、initial/publish のコマンドコピーは専用ページ側で管理します。

voicevox-multi-character-v1.html を開く
Step 3 Movie

Movie adjust Tool

旧来の voice_control 調整UIです。必要時のみ利用してください。STEP3ツールとして利用し、後日仕様を更新予定です。

voicevox-control-panel.html

npm run scene-remotion:dev

Step 4 Render

書き出し (render)

STEP3の統合確認が完了したら render を実行して動画を書き出します。必要ならWAV生成+dev+renderをまとめてコピーできます。

npm run scene-remotion:render

Dialogue Pipeline Tools

svrs_script_blueprint → svrs_dialogue_base → svrs_dialogue_rendered を生成する補助ツール群です。

script-engine-v1.html dialogue-generator-v1.html dialogue-renderer-v1.html
Utility B

Script / Video Tools

別系統の台本・動画仕様編集。用途に応じて svrs_script_spec / svrs_video_spec を扱います。

script-forge-v2.html video_factory.html
Utility C

Mock Tools

Hook/Scene の見た目モック調整用ツールです。

hook-player-mock scene-player-mock
